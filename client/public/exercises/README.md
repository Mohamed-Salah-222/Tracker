# Exercise illustrations

Drop a PNG here named after the movement id, e.g. `bench-press.png`.
The ids are the keys of `MOVEMENTS` in `client/src/lib/workoutSplits.ts`.

Anything missing shows a labelled placeholder in the app rather than a broken
image, so these can be added a few at a time.

Suggested: 4:3, transparent background, anatomical/muscle-highlight style.

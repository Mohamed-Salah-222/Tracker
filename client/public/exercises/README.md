# Exercise illustrations

One file per movement id, e.g. `bench-press.webp`. The ids are the keys of
`MOVEMENTS` in `client/src/lib/workoutSplits.ts`. Anything missing shows a
labelled placeholder in the app, so the set does not have to be complete.

Format: animated WebP, 1024x768 (4:3 at 2x), transparent, two frames at 700ms
looping. Near-lossless suits flat line art better than lossy and comes out
smaller. A still image is fine too, as long as it is `.webp`.

## Source

Generated from the Everkinetic open dataset (https://github.com/everkinetic/data),
CC-BY-SA-4.0, original work by Greg Priday. Attribution is still owed if these
ship publicly.
